## 4. 公式后的符号解释

- **标准式**：其中，A 表示……，B 和 C 分别表示……〔A〕；其中 N 和 N_pos 分别表示……的数量和……的数量。
- **“式中”**：式中 R 和 Λ 分别表示……和……——全文统一用“其中”或“式中”之一。
- **超参数取值写进解释**〔A〕〔B〕：λ1 和 λ2 用于协调……，默认均设置为 1；式中 λ = …，ε = …。
- **维度写进解释**〔B〕：其中 h∈ℝ^{c'}；〔F〕常把维度前置到公式前的叙述，公式后解释更短。
- **语义小结**〔D〕：σ 衡量了……的程度——不止说“表示什么”，还说“衡量什么”。
- **特例退化**〔A〕〔D〕：注意当 σ=1 时，所提策略等价于……策略；当……为常数时，该式退化为……。
- **公式后接数值算例**〔C〕：例如，一个……编码 1110₂ 等于……，它的指数是……。
- **公式后用文字复述**〔E〕：具体而言/具体来说，……——把矩阵运算翻译成文字。
- 一次解释该式**新出现**的全部符号（2–7 个）；已解释过的不重复。

## 5. 推导链条的写法

- 〔A〕**定义式 → 性质 → 特例 → 与既有做法比较**：根据公式 x.x，如下三个性质可以被总结出 + 粗体“性质 1/2/3”各一式 → 根据性质 1，……是等价的 → 当以下等式成立时就表明……是对称的。连接词：因此 / 而 / 最终 / 当……时。用“性质”代替“定理/引理”。
- 〔C〕**来源 → 近似 → 困难 → 假设 → 新式**：该公式来自于二阶泰勒级数展开 → ……难以计算 → 为了解决这个问题，本文假设……是独立的 → 新式。
- 〔F〕**直觉 → 做法 → 公式 → 作用**：考虑到……，因此……是必要的。为此……随后…… → 为了进一步增强对……的敏感性，一个关键的直觉是……。
- 〔B〕**首先—然后—最后拆算子**：假设有两个点集 S 和 T，其中…… → 然后，可以使用以下公式对……进行插值： → 最后，通过对所有……进行……。
- 〔D〕**引理—证明**：引理 1：…… → 证明：……共有 K+1 种情况…… → 情况 1/情况 2 → 以此可以类推 → 证毕。
- 〔B〕粗体编号“**定义 1。**”“**命题 1。**”，再用“其一……其二……”文字论证。
- 回指编号〔A〕〔F〕：回顾 x.x.x 小节中公式 x.1 和公式 x.2 所描述的……；由式 x-5 定义。

- 标题：“算法 x-1 ……模块的伪代码（对应结构图 x-x）”〔A〕；Input/Output 前置、带行号、行内注释。

## 9. 硬件/部署设计描述（对应轻量化与部署章）〔C〕
1. **基线先行**：先给被改造平台的规格，并内联算式（如“a×b×c×d = N 个乘法器”）。
2. **元件级改动**：添加了一个……和一个……——加什么、加在哪、加几个。
3. **开销紧跟**：只需要 n+m 个……而非 n×m 个；仅占整个芯片面积的 x%。
4. **兼容性论断**：本文可以很容易地将……嵌入到现有……中。

## 10. 反例
