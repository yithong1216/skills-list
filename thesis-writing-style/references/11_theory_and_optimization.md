- 粗体标签 + 括号名称：“定理 X.Y（被研究量 + 性质）”〔G〕，如“（算法 x-2 的收敛性）”“（ε-近似解存在性）”；“定义 3.1（……范数）”〔J〕。

### 2.5 证明写法
- 首句交代思路〔G〕：本定理的证明基于……，其关键点在于……；本证明的关键点是给出关于 T 的一组明确的……。
- 充要分两向〔I〕：“(⇒)”“(⇐)”，各自“为反证，假设……”；依然采用反证法证明该方向。
- 归纳法〔I〕：假设……对 d 成立……在此基础上，继续考虑 d+1。
- 分情形〔D〕〔J〕：情况 1/情况 2；如果 Δ≤0……如果 Δ>0……。
- 长证明分部分〔G〕：第 1 部分：求……上界；第 2 部分：推导……。
- 逐式标明依据〔J〕：其中第一个不等式由引理 x.3 而来……第二个不等式由 Young 不等式而来。
- 条件逐条验证〔J〕：对于第一个条件，……；对于第二个条件，…… → 故定理 x.3 得证。
- 连接词：首先 / 由于……，即…… / 注意到 / 不失一般性地 / 于是有 / 由……的构造可知 / 结合……可得 / 显然 / 易得 / 进而。
- 结尾：“结论得证。■”/“证毕。”/“故……得证”——**全文统一一种**。
- 省略〔G〕〔J〕：其证明步骤类似，此处略去。■；其详细求解过程此处不再赘述。

### 2.6 假设与注（Remark）
- 假设引入〔G〕：基于上述分析，本章对……做出以下假设 + 粗体“假设 x.1”，**紧跟一条注说明如何放宽**。引用连号：“假设 x.1–x.2 成立”。
- 注的四种用途〔G〕：说明假设可放宽/方法可推广；实现细节；定理条件的合理性；建模简化的合理性。
- 不用“注”字时，由“需要注意的是 / 需要指出的是 / 需要特别指出的是”承担同一功能〔I〕。
- 定义后紧跟“与……的联系/区别”说明〔G〕；脚注限定〔J〕：严格地讲，……仅为拟范数。
