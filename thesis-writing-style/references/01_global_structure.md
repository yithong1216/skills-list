# 01 全文架构：章名、节名、章间逻辑、篇幅

## 1. 章序骨架

| 位置 | 常见形式 | 说明 |
|---|---|---|
| 第 1 章 | 绪论（〔E〕叫“概述”） | 研究背景与意义 → 研究现状 →（不足）→ 研究内容与贡献 → 论文结构 |
| 第 2 章（可选） | 基础知识/研究现状独立成章 | 〔E〕“基础知识”（符号定义、常用模块、评测数据）；〔A〕“研究现状”（相关工作、数据集、评价指标） |
| 主体 3–4 章 | 方法章，章名同构 | 见 §2 |
| 系统/平台章（可选） | “系统搭建与性能测试”〔D〕 | 把前几章方法部署到真实平台统一验证 |
| 末章 | 总结与展望 / 全文总结 | x.1 工作总结（主要结论）→ x.2 研究展望 |

**硕士论文适配**：6 章结构（绪论 / 理论基础 / 方法×2–3 / 系统或部署 / 总结）与〔D〕〔E〕最接近，可直接对照。

## 2. 章标题命名模式（主体章必须同构）

| 模式 | 来源 | 模板 |
|---|---|---|
| 基于 + 技术 + 的 + 任务 + 方法 | 〔E〕 | 基于 [核心机制] 的 [任务] 方法 |
| 基于 + 技术 + 的 + 任务（无“方法”） | 〔B〕 | 基于 [核心机制] 的 [任务] |
| 面向 + 对象 + 的 + 系统名词 | 〔C〕 | 面向 [对象/场景] 的 [架构/方案] |
| 共同主语 + 的 + 方面名词 | 〔A〕 | [研究对象] 的 [网络架构设计 / 表征 / 损失设计 …] |
| 场景 × 任务矩阵（名词短语） | 〔D〕 | [单/多节点] + [感知/预测任务] |
| 成对偶的“显式/隐式” | 〔F〕 | 基于显式 [X] 的 [任务] / 基于隐式 [X] 的 [任务] |
| 面向 + 对象 + 的 + 类型词（攻击/方法/机制） | 〔G〕 | 面向 [对象机制] 的 [攻击/防御方法] |
| 基于 X 的 Y 方法研究 | 〔H〕 | 基于 [科学机理] 的 [建模] 方法研究（与绪论科学问题对应） |
| 基于 工具 的 对象 的 问题词（成对：验证/综合、规划/控制） | 〔I〕 | 基于 [形式化工具] 的 [对象属性] 的 [验证/综合] |
| 基于 模型 的 对象 任务 方法（理论章 + 应用章） | 〔J〕 | 基于 [数学模型] 的 [数据类型] [任务] 方法 |

规则：①主体章用**同一句法**；②章名 = 方法核心 + 任务，使读者从目录即可看出各章分工；③章名与绪论“研究内容”条目、结论各条**一一对应、措辞一致**（〔C〕结论章小标题与绪论“研究内容一~四”逐字对应）。

## 3. 节标题命名模式

- **方法节内固定三段**〔A〕：每个方法节下统一“研究动机 → 算法描述 → 实验分析”，所有方法章一致。
- **章内固定序列**：
  - 〔E〕x.1 研究背景（研究动机 + 相关技术）→ x.2 方法描述（问题定义 + 分模块）→ x.3 实验分析 → 本章小结。
  - 〔C〕引言 → 研究背景 → 研究动机 → 设计 → 结果评估 → 相关工作（与讨论）→ 本章总结（体系结构会议论文式）。
  - 〔D〕引言 → 系统模型（场景描述/系统模型/问题构建）→ 问题分解与求解 → 实验结果与性能评估 → 本章小结。
  - 〔F〕引言 → 任务定义/原理介绍 → 方法节 → 实验和评估（性能与消融 → 可视化 → 敏感性 → 实时性 → 实际场景演示）→ 本章小结。
- **冒号式三级标题（自带结论）**〔C〕模板：「主题：问题陈述」（如“[技术路线]：上层算法缺乏对底层硬件的感知”）。适合绪论“挑战”小节。
- 实验三级标题统一用名词短语：“实验设置”“与现有方法的比较”“消融研究”“时间复杂度分析”“可视化和定性分析”〔E〕。

## 4. 章间逻辑的组织方式

| 组织 | 来源 | 表达方式 |
|---|---|---|
| 递进链（每章以前章为基础） | 〔F〕 | 论文结构段每章一段：“第X章在……基础上，重点研究……问题，即：如何……”；结构图用箭头标注依赖 |
| 由低到高 + 子问题并列 | 〔B〕 | “首先研究……，然后研究……，最后研究……，其逻辑关系如图 1-X 所示” |
| 并列 → 汇合 → 支撑 | 〔C〕 | 结构图：两章并列、汇入第三章、第四章以虚线“技术支撑” |
| 2×2 矩阵 | 〔D〕 | 两个维度各取两值形成四格，摘要、绪论、章名、结论全部沿用 |
| 两条主线各两章 | 〔E〕 | 主线一（3、4 章）+ 主线二（5、6 章），用一条统一线索串起 |
| 鱼骨图：困难 ↔ 章节 | 〔A〕 | N 条困难与第 3–6 章一一对应，括号标签说明各章角色（如“基准算法”） |
| 攻 → 攻 → 防 → 防（两大视角） | 〔G〕 | 结构图两块虚线框，箭头标注章间依赖 |
| 两条平行线，每线内“分析 → 综合” | 〔I〕 | 两个并列虚线框，各含一章分析、一章综合 |
| 理论章 → 应用章 | 〔J〕 | 左理论框、右应用框，应用框内标出用到哪几类理论 |
| 时间维度 2 章 + 空间维度 1 章 | 〔H〕 | 表格式研究框架图 |

**更多节骨架**
- 〔J〕三个应用章完全同构：引言 → 问题形成 → 优化求解 → 算法分析（复杂度/收敛性）→ 数值实验 → 本章小结。
- 〔G〕引言 → 背景知识与问题建模 → 方法设计与分析 → 拓展讨论 → 仿真评估 →（实验验证）→ 本章小结。
- 〔H〕研究现状及动机 → 数据准备 → 方法设计 →（评价指标）→ 实验结果 → 本章小结。
- 〔I〕引言 → 问题描述/基本定义 → 构造 → 算法—性质—证明 → 仿真/案例 → 本章小结（实验节名不统一是反例）。

**做法**：选定一种组织，**在摘要、绪论研究内容、论文结构图、章名、结论中反复使用同一套编号与措辞**（“同构叙述”，评审最易检索）。

## 5. 篇幅分布（印刷页）

| 样本 | 绪论 | 方法章（每章） | 结论 | 备注 |
|---|---|---|---|---|
| 〔A〕 | 8 | 15–52 | 2 | 研究现状独立成章 16 页；最长一章占正文 43% |
| 〔B〕 | 25 | 19–30 | 4 | 绪论含 20 页现状 |
| 〔C〕 | 22 | 24–30 | 3+ | 四个主体章均衡 |
| 〔D〕 | 14 | 22–26 | 4 | 系统章 14 页 |
| 〔E〕 | 19 | 18–24 | 3 | 基础知识 13 页 |
| 〔F〕 | 22 | 22–36 | 6 | 绪论占 15% |

规律：绪论约占正文 **10–15%**；方法章**篇幅均衡**；结论章 **2–6 页**（短而精）。硕士论文按比例缩放：绪论 8–12 页，方法章 15–25 页，结论 2–3 页。

## 6. 反例
- 一章内人称、算法语言（中/英）、公式编号体例不统一。
- 各章引言重复讲同一套背景数字（同一个“规模增长 N 倍”出现在两章引言）。
- 绪论 1.1 写成 9 页教科书式背景。
