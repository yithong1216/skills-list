# 08 实验章节组织、消融、实物/边缘部署实验

## 1. 实验节小节顺序

| 来源 | 顺序 |
|---|---|
| 〔A〕 | (1) 实验数据和设置 → (2) 消融实验 → (3) 对比实验（评价指标放第 2 章） |
| 〔B〕 | 训练设置/数据 → 对比 → 消融 → 可视化 → 运行时间 → 应用/实际平台 |
| 〔C〕 | 评估方法 → 精度结果 → 面积 → 性能与能耗 → 设计空间/选择分析 |
| 〔D〕 | 实验设置 → 按指标分小节（速度/时延/精度/…）→ 参数设置 → 讨论 |
| 〔E〕 | 实验设置 → 与现有方法比较 → 消融 → 专项（显著性检验/复杂度/超参数）→ 可视化（含失败例）→ 局限性 |
| 〔F〕 | 对比+消融 → 可视化 → 敏感性 → 实时性 → 实际场景演示（评价指标放方法章末“训练和测试方法”） |

**推荐（检测+部署类硕士论文）**：实验设置（数据集、指标、实现细节）→ 与现有方法比较 → 消融实验 → 专项分析（参数敏感性/复杂度/效率）→ 可视化与失败案例 →（部署章）真实平台测试。

**节首路线图**〔B〕〔F〕：本章实验首先针对……进行……接着，验证……最后，还展示了……；在这一节中，类似第 x.x 节，……然后，介绍了消融研究。最后，对……进行了可视化的讨论。

## 2. 实验设置 / 实现细节
- 一段写完：数据集 → 预处理 → 框架 → 骨干 → 优化器/学习率/轮数 → 硬件〔A〕〔E〕。
- 分点〔C〕〔D〕：(1) 硬件设置 (2) 软件设置 (3) 数据集和性能评价指标；或粗体 run-in“**基准测试**”“**基准模型**”“**硬件平台**”。
- 数据集 bullet + 加粗名称〔B〕：“**X 数据集。**”+ 一两句介绍。
- 超参数取值回指公式编号〔D〕：公式 (x–3) 中的超参数 σ 设置为 0.5。
- 后续章复用设置〔A〕：实验的具体设置和 x.x.x 小节保持相同，这里不再重复描述。
- 指标定义含方向〔D〕：↑代表越高越好，↓代表越低越好；时延定义写成 l = t2 − t1。
- 〔E〕所有超参数都是基于验证集性能进行设置的。

## 3. 公平比较声明（几乎每篇都有）
- 〔C〕为了进行公平比较，实验严格设置了所有方案的相同超参数。
- 〔B〕由于相关工作 A 使用 N 个……作为输入，本章也使用 N 个输入……。
- 〔F〕为确保公平性，基线模型的……输入已统一为……。
- 〔A〕本节无法进行绝对公平的比较，在尽可能公平的条件下，……。
- 〔C〕将其他方案缩放至同一工艺/规模，并进行等面积比较。
- 随机性免责〔F〕：同一基线在不同测试中的结果可能有轻微差异，这些差异位于合理区间。
- 对比方法调参声明〔J〕：对一些算法参数进行经验性设定以保证良好的性能。

## 4. 消融实验叙述
- **为何做 → 变体定义 → 表号 → 结果 → 结论**。
- 〔A〕每个消融一个自然段，**加粗段首小标题**（“**……模块的消融实验。**”“**……数量的消融实验。**”）；引出追加实验：为了进一步探讨……，表 X 简单进行了相关的实验。
- 〔B〕节首：在本小节中，对提出方法的组成部分进行了一系列消融实验 + 约定（加粗，如“使用四分之一的训练集以减少训练时间”）；每个成分一个四级小节；首先去除……，结果，性能下降了很多，这表明了……的重要性。
- 〔F〕逐项定义变体（消融“……”表示……）；`w/o X` 命名；✓/✗ 模块矩阵；**设“同参数量”对照变体排除参数量效应**。
- 〔E〕总起段预告子问题并给节号，每子节首句“如表 X 所示，A 优于/影响大于 B，因为……”。
- 〔D〕以比较结果直接选定设计：图 X 展示了不同……方法的比较结果，……因此……。
- 〔E〕**统计显著性测试**：多随机种子重复，报告 p 值——可补多 seed 消融的说服力。
- **参数敏感性**〔J〕：为了进一步研究……参数的选取对……的影响，本节测试了不同……参数下的……性能 → 结论：……对……参数的选取具有一定的鲁棒性；或**把参数当方法变体并入对比表**（各取值一行），正文解释变化规律。
- 无消融表的理论论文〔G〕〔I〕〔J〕：用“施加/不施加某约束”的结果对比图、参数扫描、不同情形、算法变体对比代替。

## 5. 结论陈述强度
- 常用：明显优于 / 显著优于 / 有效 / 验证了 / 证明了 / 突显了 / 极具竞争力。
- 限定：约、大约、几乎持平、当时最好、在一定程度上、可能。
- “显著”最好有统计或大幅差值支撑〔E〕。

## 6. 章内“讨论”小节（局限的安放处之一）
- 〔D〕未来，可从以下几方面改进本章所提 X 方法：+ 3 条“短语标题：解释 + 补救”；直接承认“还未在实际……环境中部署”。
- 〔C〕“相关工作和讨论”节内写适用范围：目前本文仅在……平台上实现了……；由于……不支持……，因此会在未来继续跟进。
- 〔E〕单设“局限性”小节。
- 用户偏好“方法章不写局限”时：**省略本节**，局限移到结论章展望。

## 7. ★ 实物 / 边缘部署实验的写法

### 7.1 “实际场景演示”固定套路〔F〕（每个方法章末尾）
1. 目的一句：为了验证其适应性和可迁移性，实际实验在室内外两类场景中进行。
2. 场地 + 平台 + 计算设备各一句：采用……机器人/设备，算法运行在……嵌入式平台；硬件构型在图中引线标注。
3. 仿真—实际差异的处理与免责：需要说明的是，上述简化并不影响对……的验证，因为……。
4. 运行参数：速度、转向、运行时长等逐项写明。
5. 结果：“案例 × 时间步”定性图 + 实验结果显示：1）……2）……。
6. 收束：上述实际场景的结论与仿真环境中的一致，证明了……的可行性。
7. 实时性：先写测试平台型号，先承认慢再用“同一量级”挽回：在仿真和实际环境中分别达到 a Hz 和 b Hz，基本满足实时性能的要求。

### 7.2 边缘系统指标的表达〔D〕
- **时延拆分**：加载时延 / 首帧推理时延 / 平均时延；传输 / 处理 / 卡顿，并说明主导项：通过表 X 可以看出，加载时延在整个推理过程中占据主要时长。
- **功耗模式**：同一设备不同电源模式下的时延表。
- **帧率与平台并列**：表中“平台”一列（嵌入式设备 vs 桌面 GPU）。
- **用规格论证可部署性**：其尺寸仅为 a mm×b mm，因此……可作为……边缘节点。
- 资源占用（CPU %）图；复杂度的实测验证（运行时间表）。
- 精度与时延/带宽**成对出现**，用“权衡”表述；坦承精度代价（“仅减少了大约 x% 的……”）。
- 系统章按前几章任务各一小节，在真实平台统一验证；推理工具链（如 TensorRT 等）单设一节介绍。

### 7.3 硬件效率的表达〔C〕
- 面积：mm² + **面积比列**；“与……的面积相比几乎可以忽略”。
- 性能：归一化执行时间 / 加速比；几何平均标在图上，正文只摘几何平均。
- 能耗：分项堆叠柱（Static/DRAM/Buffer/Core）。
- 每个评估小节**结论先行**：先给判断，再说据此的设计决策。

### 7.4 推荐给“轻量化 + 边缘部署”章节的组合
> 部署平台与工具链（规格表 + 实物照片）→ 部署流程（导出、量化、引擎构建）→ 精度—速度对照表（含平台列、精度模式 FP32/FP16/INT8、mAP、FPS、延迟拆分、功耗/显存）→ 与其他轻量模型同平台对比 → 实际场景定性结果（逐行描述）→ 实时性结论（“满足 x FPS 的实时要求”）。比〔F〕多报功耗、量化精度损失与延迟拆分，即可超过样本深度。

## 8. 其他做法

- **实验组织的另一范式（无“实验设置”独立节）**〔J〕：每个数据集小节内依次写 数据集介绍 → 评价指标（定义 + 好坏方向）→ 对比方法 → 参数设置 → 定量表 → 视觉对比 → 参数/变体分析 → 计算效率；开篇先把各算法与适用场景对号入座。
- **案例研究与引言示例首尾呼应**〔I〕：本节继续以图 x-1(b) 所示的……为例。
- **随机生成实例的写法**〔G〕〔I〕：每组规模重复随机生成 N 次取平均，并逐一说明参数范围；“随机生成一个规模为 N 的……”。
- **实物实验硬件写全**〔G〕：CPU 型号、内存、运行平台、像素与物理尺寸换算；实物照片标注关键对象。
- 效率报告〔H〕〔J〕：训练时间与显存给具体值；写明实验平台软件版本与 CPU/内存配置。
- 数据集介绍〔J〕：数据集名 + 引用 + 一句话内容；结果节开头再用一两句重述数据背景〔H〕。
- 对异常结果主动披露〔H〕〔J〕：某类样本数极少；本文某变体效果不足——直说。
