# 03 绪论（第一章）

## 1. 小节组织（四种方案）

| 方案 | 来源 | 小节 |
|---|---|---|
| 标准四段 | 〔D〕〔E〕〔F〕 | 1.1 研究背景与意义 → 1.2 研究现状（按方向分 3–5 个三级节）→ 1.3 研究内容与（创新点/结构安排） → 1.4 论文组织结构 |
| 现状后加“不足”节 | 〔D〕〔I〕 | 1.2.x「现有工作的不足」——按方向各一段，逐条映射到各章 ★推荐 |
| 挑战导向 | 〔C〕 | 1.2「挑战与机遇」：每个三级节 = 一个挑战 = 一章，冒号式标题 + 本节小结 |
| 极简（现状独立成章） | 〔A〕 | 1.1 背景与意义 → 1.2 困难与挑战（4 条）→ 1.3 研究内容及组织架构 |

## 2. 1.1 研究背景与意义

**典型展开（漏斗）**：政策/宏观 → 领域定义 → 应用 → 核心矛盾 → 本文关注点。
- 政策起笔〔B〕〔D〕〔F〕：以国家层面的发展规划或产业战略起笔，一句点到即止，随即转入领域。
- 概念界定〔E〕〔F〕：……能力是……最重要且最基础的能力之一 → 一句话立论。
- **对举定义**〔E〕：……主要分为 A 与 B 两类，其中前者的目标是……，后者的目标是…… → 适合定义“对齐/融合/检测”等核心概念。
- 应用配图〔A〕〔B〕〔F〕：多栏应用场景照片，或“应用领域 + 子图编号”的 bullet。
- 转折收窄〔A〕：然而，经典的……已经无法满足……，因此……应运而生。本文主要探究如何在……下设计……。
- 问题锚点〔E〕：把三个问题用引号短语标出（“……不足”“……困难”），作为后文“三个方面”的锚。
- 末句预告全文〔F〕：具体而言，首先……；其次……；最后……。〔B〕交代实验设定：本文大部分实验以公开数据集为主，以保证可复现性。

## 3. 1.2 研究现状

**组织原则：按问题/方向/表征分类，不按时间**（全部样本）。
- 〔B〕按若干“问题方向”；〔D〕按“任务×规模”四格；〔F〕按“学习方法/表征/推理”；〔E〕按“任务→方法类别”到四级标题；〔A〕按“传统→现有范式→本文范式”。
- **节首导读**〔F〕：本节将首先介绍……，并接着介绍……，在阐明技术发展路径的同时，总结已有工作中的不足之处。
- 子节起句定位意义〔B〕〔D〕：作为……中的一个基本主题/关键技术之一，……的主要任务是……。

**逐篇评述句式**
- 〔B〕X 研究了……；而 Y 则……。
- 〔E〕与……不同的是，X 首次将……引入……。
- 〔D〕XX 等人 + 假设/设计了/提出了……。
- 综合句〔B〕：分析上述两项工作的原理，……和……都……——把两条线并拢。

**指出不足（克制、对事不对人）**
- 〔D〕然而，上述工作均假设……，而忽略了……；或“……不适用于……受限的……”。
- 〔F〕虽然……，但……面临若干问题：首先……；其次……。
- 〔F〕用“仅”“并未”点到为止：但……并未将……用于……层面。
- 〔C〕不足落在“与硬件/系统不匹配”：需要较为复杂的软件或硬件支持，才能在现有平台上运行。

**★“现有工作的不足”小节（最值得模仿）**〔D〕
```
当前，已有很多研究从 A、B 方面开展了研究……（总述）
[方向 1] 主流方案/大部分工作关注 X。然而，实际场景中……。因此，本文针对……，设计……机制。
[方向 2] ……（同构，共 N 段，N = 方法章数）
```
→ 把“不足”直接转写成各章研究目标，评审一眼看到“章章有来由”。〔C〕“本节小结”同理：综上所述，本节深入探讨了…… + 4 条 bullet 各对应一章 + 因此……是亟待解决的问题。
- 〔I〕第二例：现有……的研究存在如下的问题：+ 4 条编号，每条“针对……问题，现有的研究主要聚焦于…… → 目前尚缺乏…… → 同时，现有的工作也未……”，4 条与第 3–6 章一一对应。

## 4. 1.3 研究内容与贡献

**结构**：总述段 → 研究框架图 → N 条（与方法章一一对应）→（可选）综述句。
- 总述〔B〕：首先研究……，然后研究……，最后研究……，其逻辑关系如图 1-X 所示。〔E〕先给“两两分组”的地图：前两项成果以……为代表任务，聚焦于……方面。
- 框架图：〔C〕四列“关键挑战/解决方案”；〔F〕技术框架图 + 内容关系图；〔B〕三行方框图 + 右侧问题标签。
- **核心概念加粗定义**〔C〕〔F〕：对本文核心概念粗体定义，或粗体突出“核心矛盾”。
- 每条格式：
  - 〔B〕「1）基于 X 的 Y」粗体小标题（= 章名）+ 150–400 字：问题 → 方法 → 量化 → 开源。
  - 〔C〕「研究内容 X：面向……的……。」粗体标题 + 一段（问题→做法→效果）。
  - 〔F〕粗体标题 + 三拍：在……之后，随之而来的问题是： → 具体而言，针对……设计…… → 进一步地，面向……改进……。
  - 〔E〕首先研究……，旨在通过…… → 虽然……但是现有……难以…… → 为此本文提出了**……方法（缩写）** → 具体来说…… → 实验结论 → 通过本项研究工作……。
- 创新点：多数样本**没有**独立的“创新点一/二/三”小节，创新融入研究内容条目与结论；若学校/导师要求列创新点，可在 1.3 末单列 3 条，每条 ≤2 句。
  - 〔J〕单列“主要创新点”：本文的主要创新点总结如下：第一：……第二：……，每点“提出 X → 与已有方法的区别 → 技术要点 → 实验结论（量化比较对象数）”；并**如实写出非最优**（“仅次于一种基于……的方法”）。
  - 〔H〕两层创新分句写：问题/理论层创新（加粗核心句）+ “在算法创新方面，……”。

## 5. 1.4 论文结构

| 写法 | 来源 | 句式 |
|---|---|---|
| 每章一 bullet，主体章写成一段贡献摘要 | 〔A〕 | 本文共分为 N 章，具体组织如下：+「[章主题]：第四章围绕……进行了三方面的研究。首先……然后……最后……」 |
| 单段，每章一句完成时 | 〔B〕 | 本文后续的结构安排如下：第X章介绍了……，包括……，提出了……。 |
| 每章一段，递进依赖 | 〔F〕 | 第X章在……基础上，重点研究……问题，即：如何…… |
| 每章一段，“第X章为……，旨在……” | 〔E〕 | 第一章为绪论，旨在全面介绍研究背景与意义 |
| 含方法关键词与结构图 | 〔D〕 | 本文共分 N 章，整体研究思路和基本组织结构如图 1-X 所示 |
| 主语一律“该章”+ 完成时 | 〔J〕 | 第X章……。该章提出了……（全称，缩写）…… |

配图：多数样本配“组织结构图”（若 1.3 已配框架图，1.4 可不再配）。结尾句：第 N 章对全文进行总结，并对……的未来研究进行展望。

## 6. 其他做法

- **“关键科学问题”式**〔H〕：针对……任务，如何……是一个关键科学问题。用 1.2「关键科学问题」代替“研究现状”。
- **动机句收束每个现状分支**〔G〕：这正是本文研究的主要动机；类末归纳共性：值得注意的是，上述研究工作大都有一个共同研究范式，即……；尽管……取得了丰富研究成果，但主要仍是……。
- **现状以“局限 → 改进者”链串联**〔J〕：然而，X 使用……表示……，下一句即介绍在其基础上改进的工作。
- 现状末收束到本文出发点〔J〕：本文将摆脱……的限制。
- 节首用途声明（预备知识章）〔I〕：下文将介绍 N 种……方法，其中……用于……，……用于……——为每个工具标注后文哪章用到。
- **研究框架图（表格式）**〔H〕行 = 科学问题/研究要点/现有困难/研究思路/方法设计/应用场景，列 = 各项研究；〔J〕理论框 → 应用框；〔G〕两块视角框 + 箭头标注依赖。
- 基础章用意说明〔H〕：第二章……由于本文的研究内容同时涉及……，——明确说明基础章是为非本领域读者而设。
- 面向交叉学科读者的漏斗〔H〕：学科 → 对象 → 技术 → 数据难点 → 方法论趋势 → 回落到本文问题；可用权威背书（年度技术评选、国家规划）。
