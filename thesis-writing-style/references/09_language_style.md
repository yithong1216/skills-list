# 09 语言风格：人称、句式、衔接词、反例

## 1. 人称与指代
| 范围 | 用词 | 依据 |
|---|---|---|
| 全文/结论/绪论 | 本文、本论文 | 多数样本 |
| 章内 | 本章 | 〔A〕〔B〕〔D〕〔F〕 |
| 节内 | 本节 | 〔A〕〔C〕〔F〕 |
| 方法 | 所提方法 / 提出的方法 / 方法缩写 | 〔B〕〔D〕 |
| **避免** | 我们、笔者、本工作、本团队 | 出现处（“据笔者所知”、零星“我们”）均显得不统一 |

- 无主语主动句可用（“提出了一种……”），但避免“在本章中，本章……”式重复。
- 同一章内方法称呼固定一种（在“本模型/本文/X 模型”间摇摆为反例）。

## 2. 语态与句长
- 主动为主，被动少；句长 40–70 字，一段 5–9 句；段首主题句（总分结构）。
- 避免“被……所……”翻译腔；避免 90 字以上长句连串“，从而……”。

## 3. 高频衔接词（按功能）
| 功能 | 词 |
|---|---|
| 转折/指出不足 | 然而、但是、尽管……但……、虽然……但是…… |
| 因果/引出方案 | 因此、为此、基于此、基于上述分析、以上述意图为出发点 |
| 递进 | 此外、进一步地、更进一步地、在此基础上、更重要的是 |
| 展开 | 具体而言、具体来说、其中、也就是说 |
| 顺序 | 首先……其次/然后/接着/随后……最后 |
| 提示 | 值得注意的是、需要注意的是、需要说明的是 |
| 总结 | 总的来说、综上所述、总而言之 |
| 对比 | 相比之下、与……相比、与……不同的是、相反 |
| 例示 | 例如、以……为例 |

## 4. 高频学术动词
提出、设计、构建、建立、引入、实现、验证、证明、表明、揭示、展示、分析、阐述、介绍、利用、采用、优化、缓解、增强、突显、证实。
- 小结/结论用完成体“提出了/设计了”；方法描述用一般体“本节提出……”；安排段用“将介绍/介绍”。

## 5. 术语处理
- 首次出现：“中文（English Full Name, 缩写）”，如“重叠率（Intersection over Union, IoU）”。之后只用缩写。
- 方法命名：一章一缩写并加粗〔D〕〔E〕。
- 核心概念首次出现时**下定义**〔F〕，并可配生活化例子（如用“找桌子时先看到椅子”说明场景先验；用日常现象说明混淆因子）。
- 一词多义要在第 2 章统一界定〔E〕。
- **术语统一**：同一概念的多个译名（如“跨模态/交叉模态/多模态”）混用是常见反例；选定一种后全文统一，并列对象的语序也固定。

## 5.1 面向非本领域读者（交叉学科、跨方向评审）〔H〕〔I〕
- 绪论漏斗式科普，从学科讲到本文问题。
- 设“基础知识/预备知识”章，并在导语与论文结构段**说明其用意**。
- 术语首次出现：英文 + 缩写 + 白话释义（“……（即已经经过……处理的……）”）。
- 把领域数据翻译成读者熟悉的形式：在……数据中，每个样本可以被表示成一个向量。
- 生活化例子解释概念；示例图可带问句（“机器人会选择哪个目标区域？”）。
- 定义/定理后加“直观而言，……”。
- 正文对关键论断适度加粗——全文不超过几处。

## 5.2 提示与 Remark 用语
“值得注意的是”（提示取舍/陷阱）、“需要指出的是”“需要特别指出的是”“需要额外强调的是”、“换言之”、“不失一般性”、“尽管如此，……仍可……”。同一种功能全文用 1–2 个固定说法即可，避免“值得一提”泛滥。

## 6. 段落与版式
- 粗体 run-in 小标题（无编号）用于并列项：“**基准测试** 本文评估了……”〔C〕、“**拓扑地图。**”〔F〕。
- 编号：挑战/贡献用 1)2)3) 或 (1)(2)(3)；结论条目用 1. 2. 3.；全文统一一种。
- 段内嵌编号（“研究要点：1）…2）…3）…”同段）〔F〕可节省版面。

## 7. 强度与谦抑
- 可用：显著、明显、有效、极具竞争力、首次（有依据时）。
- 加限定：约、大约、在一定程度上、当时最好、几乎持平。
- 避免：“更令人惊讶的是”、“完美”“彻底解决”、无依据的“首次”。
- 〔D〕全文不用“首次”，用“一定的理论价值和现实意义”收尾，是稳妥范式。

## 8. 反例清单（样本中实际出现过，务必避免）
1. “在本章中，本章介绍了……”主语重复；同一词连写两次。
2. 人称混用：本文/本工作/笔者/我们。
3. 同一贡献在摘要、绪论、章引言、小结、结论中原样重复 5 次。
4. 每章引言重新讲一遍同一背景数字。
5. “由于页面限制”“由于篇幅所限”“由于时间限制”。
6. “提升了 x%”不区分百分点与相对提升。
7. 笔误/错字：如“比列”（比例）、“Real-word”（Real-world）、“本小结”指“本节”。
8. 算法伪代码中英文混用、首个公式无编号。
9. 结论章与正文内容不一致（概括失真）。
10. 套话重复：“这项研究对于推动……具有重要意义”出现 3 次；“极具挑战的问题”反复；“不仅……而且……”连用 4 次。
11. 同段两个“首先”。
12. 标题与内容不符（“研究现状及讨论”无讨论、“研究内容及创新点”无创新点）。
13. 交叉引用写错（图/表/算法/公式编号错位，“本文总共分六章”实为七章）。
14. 同书“本文/我们/该章/本章”混用；通篇“我们”（国内学位论文少见，需看导师习惯）。
15. 摘要自评“巧妙融合”“创新提出”“首创性地”——用事实代替自评。
16. 引用格式前后不一（上标 [1] 与行内 [11] 混用）。
17. 方法节内长篇解释标准工具（如通用优化器、信赖域法）——一句话 + 文献即可。
