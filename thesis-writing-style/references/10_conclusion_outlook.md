## 2. 工作总结

**开头段**
- 回到价值〔A〕：……不仅在……中有着重要的学术研究价值，……（与摘要首句同构）。
- 重申问题〔B〕〔E〕：本论文围绕……这一科学问题……；虽然……但是……。针对以上问题，本文从……入手，探索了……。
- 成果量化总述〔A〕：本论文共设计了 N 种算法，包括……；可加影响力陈述（开源、被采用）。
- 引出条目：本论文的主要工作总结如下：〔A〕；具体贡献总结如下：〔B〕〔F〕；本文取得的主要结论如下：〔D〕。

**每条结构**
- 〔A〕先“目的是……”再说做了什么，完成时“提出了/实现了”。
- 〔B〕现在的……技术可以实现……。然而，……依然严重影响着……。因此，本文提出了一种新的…… + 量化“实验表明……”。
- 〔F〕为……（目标）→ 然而，现有…… → 为此，本文设计了…… → 总的来说，上述方法实现了……，为……提供了良好的支撑。
- 〔D〕在……方面，本文……。针对……，设计了……。……实验结果表明……；回收复杂度：所提算法将复杂度从 O(…) 降低至 O(…)。
- 〔B〕用“突破……”四连作为总起，气势强，适合博士论文；硕士论文可改用“解决了/实现了”。
- 〔G〕考虑了面向……的……，首先……其次……最后……，该工作的创新点在于……——需要在结论里点明创新点时用。

**收束段**〔D〕：综上，……，具有一定的理论价值和现实意义。

## 3. 研究展望

**导语**
- 〔A〕尽管如此，……依然存在许多有挑战且尚未被解决的问题。本论文认为未来值得继续深入研究和探索的方向包括：
- 〔B〕基于前期研究经验，本文给出以下未来的研究展望：
- 〔E〕为此，以下的相关方向在未来还需要更加深入的研究：
- 〔J〕……但依然存在一些问题和挑战需要更深入的研究。本课题的后续研究工作可以从以下几个方面考虑：

**每条写法：现状/趋势 → 问题 → 方向**
- 〔A〕粗体关键词 + 冒号 + 一两句：“……与……的平衡：现状……但是……。未来可以针对性地研究……”。
- 〔D〕**补全自身假设**：本文目前所设计的……仅考虑了……，未考虑……。然而，随着……，未来……；列具体新方向（如引入更多数据源）。
- 〔F〕**把自身局限写成未来工作**：本文所提方法仍有一些优化和可扩展的空间：1）……仍面临挑战，已采取措施但没有从根本上解决……——适合“方法章不写局限”的用户，把局限集中在此处。
- 〔B〕展望是新课题而非局限，每条带文献，结尾意义句“对……具有重大价值”。
- ★**展望 = 局限的集中安放处**〔I〕：每条“本文在……中采用了/假设了……。然而，……。未来的研究可……”；局限具体到假设（确定性、单智能体、离线、完全可观等），并给出可行路径——最适合“方法章不写局限”的用户。
- 〔J〕每条“指出局限 → 给出可行路径 → 点出具体方法名”（如“未来研究工作可以考虑利用在线版本的……”）。
- 〔G〕概念标题 + 冒号，模式“本文已……；然而……；因此未来将……”。
- 〔H〕以新数据/新模态为方向，每条“与本文关系 → 新技术进展 → 已有方法 → 机会”，收句“将是极具价值的研究方向”——篇幅易过长，硕士论文每条 3–5 行即可。
- 条数 3–6 条（全部样本均在此范围）。

## 5. 反例
- 结论章全无数字，且与正文对某章的描述不一致。
- 结论条目原样复制各章小结。
- “由于时间限制”。
- 结论与摘要几乎逐句同构、缺少全文层面的提炼。
- 展望偏宏大（如通用人工智能）而与本文工作脱节。
