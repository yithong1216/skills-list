# 范例代号说明

本 skill 用字母代号指代十种典型的理工科学位论文写法范例；文中所有例子均为通用句式模板。

| 代号 | 方向 | 论文类型 | 学科大类 |
|---|---|---|---|
| 〔A〕 | 视觉检测 | 算法型 | 计算机 |
| 〔B〕 | 多模态定位 | 算法型 | 控制科学与工程 |
| 〔C〕 | 体系结构·模型轻量化 | 软硬件协同型 | 计算机 |
| 〔D〕 | 边缘计算·视频系统 | 系统优化型 | 信息与通信 |
| 〔E〕 | 视觉-语言多模态 | 算法型 | 计算机 |
| 〔F〕 | 机器人导航 | 算法 + 实物型 | 控制科学与工程 |
| 〔G〕 | 网络化系统 | 控制理论型 | 控制科学与工程 |
| 〔H〕 | 深度学习 × 交叉学科 | 交叉学科型 | 控制科学与工程 |
| 〔I〕 | 形式化方法 | 理论型 | 控制科学与工程 |
| 〔J〕 | 低秩稀疏优化 × 图像处理 | 优化建模型 | 信息与通信 |

篇幅相关建议见各文件“硕士论文适配”。

## 各范例最突出的写作特征（一句话）
- 〔A〕方法章固定“研究动机—算法描述—实验分析”三段式；章引言单段预告；公式“如下：→其中…分别表示…→性质 1/2/3”。
- 〔B〕无独立章引言，「x.1 研究背景」兼任；贡献在摘要/绪论/结论三处同构（问题→方法→数字→开源）。
- 〔C〕体系结构论文风格：「x.1 引言」含贡献列表；小结写“关键见解 + 倍数”；硬件“基线—改动—开销”三段式。
- 〔D〕绪论设“现有工作的不足”小节并逐条映射到各章；系统优化“建模→约束→NP-难→分解→引理→算法→复杂度验证”；局限写在章内“讨论”。
- 〔E〕高度模板化：章名「基于…的…方法」、方法名加粗缩写；图题承担流程叙述；定性分析含失败案例与显著性检验。
- 〔F〕独立「x.1 引言」+ 显式回指上一章；图题即方法摘要；每章末“实际场景演示”固定套路。
- 〔G〕章引言首句承接上章并转换研究视角；问题建模 P₀→P₁→三点任务；定理—证明—解读；仿真逐图回扣定理编号；每章小结附 i)ii)iii) 展望。
- 〔H〕面向非本领域读者：漏斗式科普、第二章专讲交叉学科基础、交代“图怎么读”；结果“定性→定量→总结”；结论式小节标题；通篇用“我们”（少数派）。
- 〔I〕绪论单设“现有工作的不足”4 条对应四章；章引言含叙事式动机示例 + “能否……？”研究问题；定义—直观—定理—直观—证明—例复验；运行示例贯穿全章。
- 〔J〕理论章 → 应用章两层结构；应用章节骨架完全同构（引言/问题形成/优化求解/算法分析/数值实验/小结）；ADMM 子问题过渡套路；指标与好坏方向同写；局限只放结论章。
