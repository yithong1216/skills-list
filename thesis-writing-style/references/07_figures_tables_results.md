# 07 图表在文中的表达与结果分析

## 1. 表格的引出（前导句）

| 句式 | 来源 |
|---|---|
| 表 X 在……数据集上对比了……，并测试了…… | 〔A〕 |
| 表 X 显示了……数据集上的定量评估结果 | 〔B〕 |
| ……的比较结果如表 X 所示 / 定量结果列于表 X 和表 Y | 〔B〕 |
| 表 X 展示了在……数据集上…… | 〔C〕 |
| 表 X 展示了……在不同……模式下运行 Y 的……时延和……时延。 | 〔D〕 |
| 表 X 总结了在……数据集上……的结果 | 〔E〕 |
| 表 X 展示了对关键模块的消融实验结果 | 〔F〕 |

**引出后立即解释表内概念**〔D〕：“平均时延”指……；“……模式”表示……。他人结果来源声明：表中所列其他方法的结果直接取自原始论文。

## 2. 结果分析五步

```
引出 → 总判 → 逐项对比（数字）→ 归因 → 收束
```
- **总判**〔B〕〔C〕〔E〕：X 方法在所有评估指标上都明显优于所有现有方法。/ 总的来说，提出的方法优于所有最近的……方法。
- **逐项对比**：
  - 〔E〕与最先进的……方法 A 相比，X 在……（指标）上提升了……。
  - 〔F〕**相对提升 X%（从 a 提升至 b）**。
  - 〔A〕括号对照：(a%/b% vs. c%/d%)、(m FPS vs. n FPS)；斜线并列：分别提升了 a/b/c 和……。
  - 〔D〕分别比 A 提高 a%，比 B 提高 b%。
  - 倍数〔D〕〔F〕：大约 m 倍和 n 倍的显著提升；运行速度相比于 A 提升了近 m 倍。
- **归因**：
  - 〔B〕〔C〕这主要是因为……；这是因为本章方法……消除了……。
  - 〔B〕第一个原因可能是……；第二个原因是……；更重要的是，……。
  - 〔F〕……之所以能够有明显的……提升，主要原因在于以下几点：1）……。
  - 保守归因〔E〕〔F〕：这可能是因为……；本文推测/本文认为，……。
  - 例外 + 原因〔A〕：但是这个结论并不适用于……，这是因为……。
- **收束**〔A〕〔D〕〔F〕：这进一步证明了……具有较大的优势；这突显了……的关键作用；这证明了……的有效性；**在所有方法中，……最……**。
- **编号结论**〔E〕〔F〕：可以得出以下结论：1）……2）……（嵌在同一段内）；本文观测和分析总结如下：1. ……（观察→原因→强调）。
- **多角度**〔A〕：从精度上看，表 X 显示了……；从检测速度来讲，……。
- **趋势**〔C〕：随着……的减少，X 的优势变得更加明显。

## 3. 承认弱势（不回避）
- 〔D〕仅减少了大约 x% 的……，但……极具竞争力——轻量化/部署论文必备。
- 〔E〕需要注意的是，X 相对于 A 的改进并不大，但 A 的推断速度远远慢于 X——改进不大，但在另一维度有优势。
- 〔F〕推理速度较慢。然而，它仍然保持了与……同一量级。
- 〔A〕尽管 A 达到了 x%，但其检测速度并不理想。
- 〔C〕原始……的精度损失很严重，仅作为参考——不可比基线明示。

## 4. 对比他人的措辞
- 事实 + 原因，不贬低（全部样本）：尽管 A 具有……，但它需要额外的……；A 在……方面表现良好，但在……方面表现较差——先承认长处。
- 排比〔B〕：与 A 相比，提出的方法利用了……；与 B 相比，提出的方法不需要额外的……。
- 禁用：“较差/不合理/失败”等贬词直接评他人方法。

## 5. 表格体例
- 最优**加粗**；次优**下划线**〔F〕或双色〔A〕。
- 指标带方向箭头（如 SR↑ SPL↑ DTS↓）〔D〕〔F〕。
- 增益列 / (+Δ) 标注〔A〕。
- **所提方法置末行**，横线与基线隔开〔F〕；或置顶〔D〕——全文统一。
- 硬件平台作为一列（部署论文）〔D〕，缺失写“未报告”。
- 能力对勾行（“无需……数据 ✓/✗”）嵌入结果表头〔C〕——同时展示“能力对比+数值对比”。
- 表脚注说明缩写与加粗含义〔F〕：加粗表示对应场景表现最好。

## 6. 图的引用与描述
- 〔A〕图 X 比较了两种……在……类别上的可视化效果，可以看到……。
- 〔B〕如图 X 所示，当……时，……。
- 多面板逐一引用〔C〕：图 X 的中间图比较了……；图 Xa 比较了……。
- 定性图按行/时间步叙述〔D〕〔F〕：具体而言，第 x 行……；在时间 t3，……因此，在时间 t4，……。
- 定性可视化〔E〕：图 X 可视化了……，并与……进行了比较。→ 读图说明（颜色对应表示……）→ 成功例 → 对比他法（当情况变得复杂时，A 倾向于忽略……。相反，X……）→ **失败案例与归因**（这个失败案例是由于以下两个原因：(1)……(2)……）。
- **交代“图怎么读”**〔H〕：图 X 展示了……，其中每个点代表……，颜色反映了……。同类可视化图题统一格式。

## 7. 图题、表题
- 中英对照（按学校要求）；图题在下、表题在上（遵循学校规范）。
- 命名：“X 在不同 Y 下的 A 和 B 对比”〔C〕；“平均……时延对比”〔D〕；“……性能与其他基线模型的对比”〔F〕。
- **长图题承担叙述**：〔F〕框架图图题 3–4 句“首先/随后/接着/此外”写完流程；〔E〕图题逐一定义图中符号与颜色；〔B〕图题含结论（“本章方法的结果比……好很多”）。
- 表题含说明句〔A〕〔E〕：在……数据集上与现有模型的比较。A、B 和 C 分别表示……；所列数据截止到某日期。

## 8. 数字口径（重要）
- mAP、准确率等**绝对差写“x.x 个百分点”**；只写“提升了 x%”而不区分口径是常见的含糊写法。
- 相对提升写“相对提升 x%（由 a 提升至 b）”〔F〕。
- 倍数用于速度/能效（〔C〕〔D〕〔F〕）。
- 同一核心数字在摘要、绪论、章小结、结论中**完全一致**（〔C〕三处复现同一组倍数）。
- 正文不必抄表内全部数字，只摘关键 1–3 个〔B〕〔C〕。

## 9. 其他做法

- **结果“定性 → 定量 → 总结”三拍**〔H〕：具体样例的含义解读 → 指标 + 统计检验/箱线图 → 基于以上直观的定性分析和系统的定量对比结果，本文认为……；与动机呼应：这一结果与预期相同，验证了关于……的动机。
- **结论式小节标题**〔H〕：方法名 + 鉴定出了/提示了/可以……（标题即结论）。
- **计数式总结**〔J〕：在 N 个场景中的 M 个取得了最高的……值；在 N 个序列中的 M 个获得了最高的……，其平均……为 x%。
- **指标 = 定义式 + 其中 + 好坏方向**〔J〕：……指标的值越大，表明……的性能越优；……指标的值越接近 1，表明……的偏差越小；由定义可知，一个更高的……值代表一个更优的……。无真值时先立理由：由于无法获取理想的……真值，因此本节实验中采用了 N 种常用的无参考评价指标。
- **评价指标四要素**〔H〕：名称 → 衡量什么 → 数值方向 → 公式 + 其中；必要时加公平性约定（只在所有方法都可处理的样本上计算）。
- **视觉对比逐方法点评**〔J〕：根据图 X 可知，A 和 B 的结果受……的干扰较为严重 → 困难场景单独点评：在具有挑战性的……场景中，只有本文提出的方法成功……；配局部放大框。
- 取舍披露〔J〕：参数取 a 与取 b 精度接近，但前者需要更长的运行时间；弱方法略去需说明“由于……结果不尽人意而没有在图中展示”。
- 仿真结果回扣定理编号、与理论不符时主动解释〔G〕——见 `11_theory_and_optimization.md` §6。
- 案例数字化叙述〔I〕：可节省 N 个单位的代价；其……值为 a，显著大于最优值 b。
- 实物照片 + 抽象模型并列成一图〔G〕〔I〕。
- 外部验证〔H〕：有趣的是，近期独立研究验证了与本文结果相似的……——用独立文献印证结果。

## 10. 反例
- 表内不标最优，读者需自行比较。
- 评价指标在表格之后才定义——先定义再出表。
- 同一表内同一列混用毫秒/秒/小时单位。
- 只写“如表 X 所示”而无分析。
- 英文图题拼写错误（如 “Real-word”）。
