# 02 摘要与关键词

## 1. 段落结构（共有骨架）

```
① 背景与价值（1 段）：领域定位句 → 应用 → 核心矛盾/挑战
② 总思路句：本文以……为切入点/从……两个方面入手，开展了以下研究：
③ 3–5 段并列工作：首先/其次/再次/最后 或 (1)(2)(3) 或 其一/其二
   每段四拍：针对……问题 → 提出……（方法名）→ 关键设计一句 → 实验结果
④（可选）综上所述/总而言之 收束段
⑤ 关键词 5 个左右
```

## 2. 各部分句式

**① 开头定位句**
- 〔A〕本论文旨在研究……下……的……。
- 〔B〕……是……的基础，在……等场景下具有广泛应用。
- 〔F〕……能力是……在……中工作的关键基础。
- 〔D〕先给领域定义（……是……），再“其中，……是最常用、最具潜力的……”逐级收窄。

**② 现有不足**
- 〔D〕四连否定：仅关注……，未考虑……，忽视……，难以……。
- 〔E〕并列短语：有效性受……制约、缺乏……、易于……、难以……。
- 〔C〕传统的……通常采用……，导致……。

**③ 总思路句**
- 〔F〕本文以构建……和……两大能力为切入点，随后各用一句**定义两个核心概念**（“……能力指……”）。
- 〔C〕本文从……和……两个方面入手，开展了以下四项研究工作。
- 〔A〕论文的主要贡献包含以下几方面：+ 项目符号。

**④ 每项工作（四拍）**
- 〔B〕首先，针对……问题，提出……方法。
- 〔E〕针对……的问题，利用……作为……，提出了一种……。
- 〔A〕通过……证明和……分析，本文发现……可以显著提升……。
- 〔C〕每项先一句领域价值（“其一，……可以降低……”），再“传统…导致…→本文提出…→结果”。

**⑤ 量化结果（写数字的 3 篇）**
- 〔B〕在 X 数据集上，……分别优于现有最佳算法 a% 和 b%。
- 〔C〕与……相比，该设计实现了 X 倍的加速和 Y 倍的能效提升。
- 〔D〕多指标并列：……降低了 a%，……提升了 b%。
- 不写数字的样本用定性词：“取得了较佳的平衡”〔A〕、“明显优于”〔E〕、“显著提升了……效率”〔F〕。

**⑥ 收束段**
- 〔C〕综上所述，本论文通过……，把各项工作再串成一条逻辑线。
- 〔E〕总而言之，本文对……进行了深入研究，并以……为代表提出了……。
- 〔D〕综上，本文考虑……等多方限制，……，具有一定的理论与现实意义。

**理论型/交叉学科摘要**：〔G〕〔H〕〔I〕〔J〕摘要**均不写数字**（10 篇中 7 篇不写；写数字的〔B〕〔C〕〔D〕都是实验/工程型）。
- 〔I〕总述段：然而，在实际运行中，……往往面临……的挑战。一方面，……；另一方面，……。因此，如何在……下实现……，成为……的关键问题。基于此，本文以……为……，系统性研究了……。
- 〔I〕每条贡献四拍：针对……，本文提出了一种基于……的…… → 该框架的核心思想在于，通过引入……，使得…… → 该统一视角不仅避免了……，同时也揭示了…… → 通过案例研究表明，……。
- 〔G〕以“随着……等技术的不断融合发展”起笔；贡献条目以“研究了面向……的……”起首，写理论性质（收敛性、性能边界）代替数字。
- 〔H〕每个工作段：加粗标题 → 任务是什么 → 传统方法“然而” → 针对这一问题，本文分析了……，认为…… → 基于这一发现，本文提出了……方法 → 结果定性。
- 〔J〕先“理论总述”一段，再“具体研究内容如下：”+ (1)(2)(3) 应用条目——理论 + 应用型论文的摘要结构。

## 3. 关键词
- 数量 5 个最常见；构成 = **任务/领域词 + 核心技术词 + 本文核心概念**。
- 〔C〕全是方向术语，无具体方法名；〔A〕以问题术语为主。
- 避免：关键词只覆盖前半部分工作（〔D〕后两章贡献无对应关键词）。

## 4. 推荐写法（硕士论文）
- 长度 **≤1 页**（约 2 页的摘要显得冗长）。
- 实验型论文每项工作写 **1 个核心数字**，数字与绪论、章小结、结论**完全一致**。
- 每项工作句数 3–4 句，与章名一一对应、顺序一致。
- 英文摘要与中文逐段对应。

## 5. 反例
- 同一段内两个“首先”（段首“首先，……”后又“首先，设计了……”）。
- 结果句全用“不仅……而且……”，重复 4 次。
- 摘要长达 2 页、把每章全部数字搬入。
