# 05 本章小结（每章结尾）

## 1. 十个样本统计

| 样本 | 标题 | 长度 | 时态 | 写数字 | 写不足 | 引出下章 |
|---|---|---|---|---|---|---|
| 〔A〕 | 本章小结 | 1 段 ~280 字 → 2/3 页 | 完成时 | 否 | 后几章写 | 否 |
| 〔B〕 | 本章总结 | 1–3 段 210–520 字 | 完成时，常无主语 | 仅一章 | 否（仅“值得探索的方向”） | 否 |
| 〔C〕 | 本章总结 | 1 段 150–200 字 | 完成+一般 | 是（倍数，与摘要一致） | 否（放“讨论”节） | 否 |
| 〔D〕 | 本章小结 | 1 段 6–10 行 | 完成时 | 前 2 章是 | 否（放“讨论”节） | 否 |
| 〔E〕 | 本章小结 | 1 段 ≤8 行 | 完成时 | 否 | 否（单设局限节） | 否 |
| 〔F〕 | 本章小结 | 1 段 280–420 字 | 完成时 | 否 | 否（仅“能力边界”一词） | 仅一处一句 |
| 〔G〕 | 本章小结 | 1–2 段 230–440 字 | 完成时，常省主语 | 否 | 否（写 i)ii)iii) 展望） | 否 |
| 〔H〕 | 本章小结 | 3–5 段 1.2–1.6 页 | 完成时，主语“我们” | 否 | **是**（+对策） | 否 |
| 〔I〕 | 本章小结 | 1–2 段 130–280 字 | 完成+一般 | 否 | 否（第 2 段为“范围说明”） | 否 |
| 〔J〕 | 本章小结 | 1 段 300–450 字 | 完成时 | 否 | 否（局限只在结论章） | 否 |

**共识**：完成时（10/10）、一段为主、不引出下一章（10/10）、不写数字（7/10）、局限不放小结（8/10，〔A〕〔H〕例外）。

## 2. 结构（通用四步）

```
① 总括句：本章针对……问题，提出了……（方法全称/缩写）。
② 方法回顾：首先，……；其次/接着，……；最后，……。（或 1)2)3)）
③ 实验结论：在……数据集上的实验结果表明，所提方法……（可含 1–2 个核心数字）。
④（可选）意义/定位：该方法……，为……提供了……。
```

## 3. 各步骤句式

**① 总括句**
- 〔D〕**针对……，本章提出了一种……方法 X**（多章逐字同构）。
- 〔F〕本章针对……的问题进行研究。/ 本章研究了针对……的……方法。
- 〔E〕本章以……任务为示例，探索了……对于……的效果。
- 〔A〕本章针对……提出了 N 种亟待解决的问题，本章主要由三部分组成：1)…… 2)…… 3)……。
- 〔C〕本文提出了一种名为 X 的新型……，其关键见解是……（key insight 句式，体系结构风格）。
- 〔G〕本章研究了……问题。首先，提出了……。然后，……。最后，……。
- **因果起句**〔J〕：由于……（已有问题），本章提出了……用于……。

**② 方法回顾**
- 〔D〕首先，本章建立了……其次，本章建立了……最后，本章采用……。
- 〔F〕在本章中，首先提出了……接着，……最后，……。
- 〔F〕**“不同于……”定位句**突出新意：本章的方法不同于传统的基于……的范式；不同于前述章节针对……的研究，本章……。
- **按“问题动机 → 算法”演进链回顾**而非按小节罗列〔J〕：考虑到……，因此本章进一步将 X 推广而提出了 Y；为了进一步处理……，本章随后提出了……。
- 对比定位句〔G〕〔I〕：与大多数现有工作不同，……；与以往研究相比，该方法不仅能够……；与上一章仅考虑……不同，本章进一步探讨了……。

**③ 实验结论**
- 不写数字〔B〕〔E〕：大量实验表明，提出的方法超过了已发表的其他方法的性能；在 N 个大规模基准数据集上的综合实验证明了本文的方法显著优于……。
- 写数字〔B〕〔C〕：X 相对于 A 和 B 分别实现了 m 倍和 n 倍的加速；X 可以达到……的平均误差，分别提高了 a% 和 b%。
- 定性收尾〔A〕：并在当时的多个数据集上取得了最先进的性能。
- 验证句〔G〕〔J〕：仿真结果/数值实验验证了所提出方法的有效性。

**④ 意义**
- 〔E〕……从而使真实世界应用中的模型更具……——结果升华为价值。
- 〔C〕以“满足了……需求”收尾，呼应绪论。
- 〔F〕并讨论了其能力边界和适应性——最轻的一笔“局限”。
- 〔G〕〔I〕本章的研究为……提供了有意义的新见解 / 为后续……研究奠定了基础、提供了新的技术路径。

**⑤ 范围说明段（不是不足）**〔I〕
- 需要额外强调的是，本章的核心内容主要集中在……。……因此本章不再对此进行额外展开。——把“未做的事”说成“超出本章范围”，适合不写局限的用户。

**⑥ 每章附展望（少数派）**〔G〕
- 未来还有以下方向值得深入探索：i）……ii）……iii）……。

## 4. 若要写不足（〔A〕式，供用户偏好允许时使用）
- 虽然本章所提出的方法均取得了不错的效果，但依然存在些许问题：1)…… 2)……，每条后接缓冲（“相关工作目前已在……中被提出”）。
- 虽然……已经取得了初步的进展，但是……表现并不好。一个原因是……，另一个原因可能是……。
- 〔B〕只用一句展望代替不足：因此未来将……与……相结合是一个值得探索的方向。

## 5. 推荐模板（硕士论文，150–250 字）
> 本章针对……问题，提出了一种基于……的……方法（缩写）。首先，……；其次，……；最后，……。在……数据集上的实验结果表明，所提方法的 mAP50 达到 xx.x%，较基线提升 x.x 个百分点，验证了……的有效性。

## 6. 反例
- “在本章中，本章介绍了……”主语重复。
- 小结与结论章对应条目几乎原样重用——结论章应重写并上升到全文层面。
- 各章小结用同一句开头且动词不变——句式可同构，但内容动词要随章变化。
- 某章小结数字与摘要不一致（如一处写“节省 4 倍”，另一处写“降低”）。
