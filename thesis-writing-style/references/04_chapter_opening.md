# 04 章引言（每个方法章的开头）

## 1. 三种形式

| 形式 | 来源 | 长度 | 特点 |
|---|---|---|---|
| A 章名下**无编号单段** | 〔A〕〔E〕 | 1 段，230–430 字 | 小结的“预告版”或“压缩摘要”；无小标题 |
| B **编号小节「x.1 引言」** | 〔C〕〔D〕〔F〕〔G〕〔I〕〔J〕 | 0.5–2 页，2–9 段 | 可含现状评述、贡献 bullet、本章安排 |
| C 「x.1 研究背景」兼作引言 | 〔B〕〔H〕 | 1–1.8 页 | 背景+现状+挑战+对策，无“本章安排” |

选一种全文统一。硕士论文推荐 **A（短，0.3–0.5 页）** 或 **B 的精简版（≤1 页，无大段综述）**。

## 2. 共同因果链（10/10）

```
① 领域定位/技术现状
② 「然而」现有方法的不足（1–3 条，可编号“一是…二是…”或 1)2)3)）
③ 「因此/为此/基于上述分析」本章提出 [方法全称（缩写）]
④ 做法概述：本章首先……，然后/接着……，最后……
⑤（可选）实验结论一句 / 贡献 bullet / 本章安排
```

## 3. 各步骤句式

**① 起笔**
- 〔A〕领域 + 价值，再点明现状：现有……均是基于……改进的。
- 〔A〕先立论点：……的……很大程度上取决于……。
- 〔D〕开门见山点题：**本章考虑 [场景]，主要研究 [机制]**。
- 〔B〕先下定义：……表示……之间的……。
- 〔D〕**用数字制造紧迫感**：把一个典型场景的资源需求算出来（如 N 路视频流所需带宽），说明问题的规模。

**② 指出不足**
- 〔A〕然而，……均……，这导致暂时无法……。
- 〔B〕逐个代表方法各一个“然而”：X ……。然而，……。Y ……。然而，……。
- 〔F〕然而，基于……的……仅能实现……。
- 〔D〕现有工作存在以下局限：一是……二是……。
- 问题化〔D〕〔F〕：如何设计……，是……的关键问题/极具挑战的问题。

**③ 提出本章方案**
- 〔F〕本章研究重点关注……问题，即如何……。
- 〔B〕**挑战—对策逐一对应**：本章介绍了一种……方法，需要克服三个挑战：…… 针对前两个挑战，本章提出了……；针对第三个挑战，本章提出了……。
- 〔C〕基于上述观察，本文提出了一种新型的……，称为 X。
- 〔E〕为此本文提出了**基于……的……方法（缩写）**——方法名加粗+缩写。
- 〔A〕本章提出一种新的……任务/设定。

**④ 做法概述**
- 〔A〕本章首先阐述了……随后进一步提出了……最后，在保留……的优势下继续采用……——一条线串起 x.1→x.2→x.3。
- 〔F〕以上述意图为出发点，本章首先提出了……。为了解决……，本章还进一步提出了……。

**⑤ 收尾选项**
- 实验结论〔A〕：在多个公开的……数据集上的大量实验结果表明，所提方法均有不错的表现。
- 贡献 bullet〔C〕〔D〕：本章工作的主要贡献如下：+ 3 条“本章提出/设计/构建了……，通过……，实现了……”，第 1 条含“与现有工作不同的是……”差异化句。
- 本章安排〔D〕：本章余下部分的结构如下：x.2 节介绍……；〔F〕不写安排，用“首先—接着—最后”段代替。
- **路线图段用将来时 + 节号做主语**〔J〕：本章主要内容安排如下：x.2 节将介绍……。接着，x.3 节和 x.4 节将分别给出……。最后，x.6 节将给出本章小结。——**推荐此时态**（用“介绍了”指代尚未出现的后文读感别扭）。

## 4. 与上一章衔接

样本中 6/10 显式回指上一章。有章间依赖时推荐显式回指：
- 〔F〕在……基础上，还需要……。前者在第X章已经讨论，而后者是本章的重点。
- 〔F〕前文第二章到第四章讨论了……能力。在此基础上，本章将重点研究另一种新的能力——……。
- 〔F〕比较式衔接，不复述上一章：与第X章讨论的……相比，……。
- 〔B〕前面章节说明……；但……，因此本章提出……。
- 〔E〕上一章从……出发，……；本章在……上更进一步，关注到了……。
- 视角转换式〔G〕：本文第 X 章揭示了……。一旦……，……。为此，本章将进一步转换……视角，深入探究……。
- 沿路线推进〔G〕：沿着第 X 章的……研究路线，本章将更深入地考虑……的最坏情形。
- 回指 + 指出上章简化〔I〕：上一章针对……的……问题，……（说明其简化假设），本章放宽该假设……；两章并回：本文的第三章和第四章分别针对……。值得注意的是，尽管……，仍然建立在……的前提之上。
- 上章方法即本章出发点〔H〕：在上一章中，所提出的 X 便是……。然而，这其实是……的一个局限。
- 理论延伸式〔J〕：第二章主要基于……介绍了……理论。作为……理论的延伸，本章……。

## 5. 其他引言元素

- **研究问题疑问句**〔I〕：由此自然引出以下三个问题：+ 3 条“能否……？” → 下文旨在回答上述三个问题。
- **叙事式动机示例 + 示意图**〔I〕：为进一步说明，下面通过一个简单的……示例进行阐释 + 图 x-1；示例在后文案例研究中复用。
- 意义 bullet〔I〕：该方法的意义可总结为如下几个方面：+ 首先/其次/最后。
- 挑战两点〔G〕：其挑战主要来自两点。一方面……另一方面…… → 针对上述挑战，本章主要贡献如下：。
- **应用章引言 = 先验 → 退化因素 → 方案对号入座**〔J〕：……可能会因如下两种因素导致……退化：(1)……(2)…… → 本章针对这两方面因素，针对第一种因素，本章将……；针对第二种因素，……。
- 把综述推给文献〔J〕：感兴趣的读者可参考综述文献[…]——章引言不写长综述。

## 6. 人称
- 章引言主语“本章”（〔A〕〔D〕〔F〕）；章内用“本文”指代本章工作易混（期刊论文搬入所致），不推荐；章内出现“我们”为不统一。

## 7. 模板（可直接套用）

**A 型单段（约 300 字）**
> ……是……中的关键问题。近年来，……取得了显著进展。然而，现有方法大多……，难以……。为此，本章提出一种基于……的……方法（缩写）。本章首先……；在此基础上，设计……以……；最后，在……数据集上验证所提方法的有效性。

**B 型「x.1 引言」（≤1 页）**
> 段 1：背景与问题（含 1 个具体数字或场景）。
> 段 2：现有方法分两类评述，各以“然而……”收尾。
> 段 3：“因此，本章提出……”+ 做法概述。
> 段 4：“本章的主要贡献如下：”+ 2–3 条（提出/设计/构建了……，实现了……）。
> （可选）段 5：“本章其余部分安排如下：x.2 节将……”

## 8. 反例
- 章引言把绪论 1.3 对应条目原样再写一遍，同一内容出现 5 次（摘要/1.3/章引言/小结/结论）——引言应侧重“为什么”，小结侧重“做了什么”。
- 每章引言都重新塞一段与绪论重复的综述。
- 节号 + 完成体指代未写的后文（“在 x.2 节介绍了……”）读感别扭——安排段用“将介绍/介绍”。
