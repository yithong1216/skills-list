# 优秀学位论文写作语言与框架

本 skill 回答“**写成什么样**”（结构、句式、语气），不管“**排成什么样**”（LaTeX 与版式请遵循所在学校的论文模板与格式规范）。

**证据基础**：10 篇近年国内工科优秀博士学位论文（含提名），按同一模板精读摘要、目录、绪论、每章首尾、公式密集页、表格分析页与结论，归纳出共识与变体。样本以字母 A–J 指代，类型见 `references/sources.md`。文中例子均已改写为**通用句式模板**（“……”与 X、Y 为占位），不含原文。

| 代号 | 方向 | 论文类型 |
|---|---|---|
| 〔A〕 | 视觉检测 | 算法型 |
| 〔B〕 | 多模态定位（控制科学与工程） | 算法型 |
| 〔C〕 | 计算机体系结构·模型轻量化 | 软硬件协同型 |
| 〔D〕 | 边缘计算·视频系统 | 系统优化型 |
| 〔E〕 | 视觉-语言多模态 | 算法型 |
| 〔F〕 | 机器人导航（控制科学与工程） | 算法 + 实物型 |
| 〔G〕 | 网络化系统（控制科学与工程） | 控制理论型 |
| 〔H〕 | 深度学习 × 交叉学科（控制科学与工程） | 交叉学科型 |

| 〔J〕 | 低秩稀疏优化 × 图像处理 | 优化建模型 |

下文计数如“7/10”指 10 篇中有几篇如此。例子格式：`〔代号〕句式模板`。

## 使用流程

1. 确认要写/改的是哪一部分，打开对应 reference（下表）。
2. 先套用 **§1 共识规则**（多数样本一致的做法），再从 reference 的“可选变体”里选一种，**全文统一**，不要混用变体。
3. 写完用 **§3 自查清单** 逐条过一遍；并检查 `09_language_style.md` 的“反例”。
4. 若用户本人或导师有写作偏好（例如方法章不写局限、某些术语的固定译法），**用户偏好优先于本 skill**。

## 1. 共识规则（10 篇中多数一致，默认照做）

**全文架构**
- 主体方法章**章名同构**：全部用同一句法，如「基于 X 的 Y 方法」〔B〕〔E〕、「面向 X 的 Y」〔C〕、「共同主语 + 的 + 方面名词」〔A〕。不要一章“基于”、一章“面向”、一章纯名词。
- 主体章**节骨架同构**：每章都是“引言/研究背景 → 方法 → 实验 → 本章小结”，三级标题名称也尽量相同（如统一「研究动机/算法描述/实验分析」〔A〕，统一「实验和评估」〔B〕〔F〕）。
- 绪论里把“问题/挑战”与后续各章**一一对应**，并配一张“研究内容与组织结构图”（9/10 配图）。

**章引言**
- 走同一条因果链：**领域/背景 →「然而」现有不足 →「因此/为此」本章提出 → 本章做法概述（首先…然后…最后…）**（10/10）。
- 方法名在章引言首次出现时**全称 + 英文缩写**（并可加粗），之后全文只用缩写。
- 章间有依赖时，**首句显式回指上一章**（6/10：〔E〕〔F〕〔G〕〔H〕〔I〕〔J〕），如“上一章基于……揭示了……。然而……”。

**章小结**
- **完成时**：“本章提出了/设计了/研究了/介绍了……”（10/10）。
- **不引出下一章**（10/10，仅一篇有一处一句例外）；止于本章，衔接放到下一章引言首句。
- **单段或 1–3 段，150–450 字**；结构 = 总括句 → 首先/其次/最后 回顾方法 → 实验/验证结论句。
- **不回顾具体数值**（7/10）；局限**不写在小结里**（8/10）：放在章内“讨论”小节〔C〕〔D〕或集中到结论章展望〔B〕〔F〕〔G〕〔I〕〔J〕。

**方法与公式**
- 公式**前**有引导句，以冒号收：“……定义如下：”“……可表示为：”“……计算如下：”。
- 公式**后**紧跟“其中，A 表示……，B 和 C 分别表示……”，一次解释该式新出现的全部符号；超参数取值可写进同句（“默认均设置为 1”）。
- **框架图先于公式**：先“X 的整体框架如图 a–b 所示”，再按模块展开公式。
- **问题建模先于方法**：优化/理论类章节把“问题形成/问题描述”独立成节（〔D〕〔G〕〔I〕〔J〕），把模型以“问题 (x.y)”编号称呼。
- 重要定义/定理后接一句**“直观而言，……”**的人话解释（〔A〕〔G〕〔I〕）。
- 设计理由用“为了……，本章……”“这是因为……”“针对第一个挑战……”说清。

**图表与结果**
- 结果段 = **引出（表 X 给出了/展示了……）→ 总判（明显优于…）→ 逐项对比（与 A 相比，…提升了…）→ 归因（这是因为/主要原因在于）→ 收束（这验证了…的有效性）**。
- 对他人方法**不贬低**：承认对方长处，再说明差异原因（“尽管……，但……”）。
- 表内最优加粗；指标名带 ↑/↓；图题、表题中英对照（若学校要求）。

**语言**
- 主语用“本文/本章/本节”，**不用“我们”“笔者”**（7/10 如此；通篇“我们”或混用的样本均显得不统一）。
- 评价指标与“好坏方向”同写：“……的值越大，表明……越优”（〔D〕〔H〕〔J〕）。
- 高频衔接：然而 / 因此 / 为此 / 此外 / 具体而言 / 首先…其次…最后 / 值得注意的是 / 总的来说。
- 首次出现术语给“中文（English, 缩写）”。

## 2. 关键分歧点（需要自己选一种并全文统一）

| 维度 | 变体 A | 变体 B | 变体 C | 推荐（硕士论文） |
|---|---|---|---|---|
| 章引言形式 | 章名下**无编号单段**（230–420 字）〔A〕〔E〕 | **编号小节「x.1 引言」**（0.5–2.3 页，可含贡献列表、本章安排）〔C〕〔D〕〔F〕〔G〕〔I〕〔J〕 | 直接「x.1 研究背景/研究现状及动机」兼作引言〔B〕〔H〕 | **B（6/10）**；硕士论文控制在 ≤1 页 |
| 章引言是否回指上一章 | 不回指〔A〕〔B〕〔C〕〔D〕 | 显式回指〔E〕〔F〕〔G〕〔H〕〔I〕〔J〕 | — | 章间有依赖时**用 B**（6/10），并列章可不回指 |
| 章引言末尾 | “本章安排”段（节号 + 将……）〔C〕〔D〕〔G〕〔I〕〔J〕 | 用“首先…接着…最后…”段代替〔A〕〔F〕 | 贡献 bullet〔C〕〔D〕〔G〕〔I〕 | 硕士论文：做法概述段即可，贡献 bullet 可选 |
| 章小结是否写数字 | 不写数字（7/10） | 写 1–3 个核心数字，与摘要一致〔B〕〔C〕〔D〕 | — | 实验型章节可写 **1–2 个核心数字**，且与摘要、绪论、结论**完全一致**；理论型不写 |
| 章小结是否带展望 | 不带（9/10） | 每章末附 i)ii)iii) 展望〔G〕 | — | 不带；展望集中到结论章 |
| 摘要是否写数字 | 写（倍数/百分比）〔B〕〔C〕〔D〕 | 不写（7/10，理论型与交叉学科全部不写） | — | 实验/工程型硕士论文**建议写**每项工作 1 个核心数字 |
| 局限放在哪里 | 章内“讨论”小节〔C〕〔D〕 | 结论章展望〔B〕〔F〕〔G〕〔I〕〔J〕 | 章小结〔A〕〔H〕 | 按用户偏好；方法章不写局限时 → 放**结论章展望**（5/10 同做法） |
| 研究现状放在哪里 | 绪论内（7/10） | 独立成章〔A〕 | 分散到各章引言/相关工作〔C〕〔H〕 | 硕士论文放**绪论**，另设第 2 章“理论基础” |
| 绪论是否单设“现有工作的不足” | 单设，逐条映射到各章〔D〕〔I〕 | 夹在现状各小节末（多数） | — | **推荐单设**，评审最易看出“章章有来由” |

## 3. 自查清单（写完一章过一遍）

- [ ] 本章章名与其他方法章同构；三级标题名称与其他章一致。
- [ ] 章引言有“然而→因此”的不足—对策链；方法名全称+缩写首次出现。
- [ ] 每个公式前有引导句、后有“其中…表示…”，符号无未定义、无重复定义；向量矩阵体例一致。
- [ ] 每张图/表在正文中被引用并**被分析**（不是只说“如表 X 所示”）；分析含归因句。
- [ ] 数字口径：mAP、准确率等绝对差写“**百分点**”，相对提升写“相对提升 x%（由 a 提升至 b）”；同一数字在摘要/绪论/小结/结论中完全一致。
- [ ] 本章小结：完成时、不引出下一章、不写局限（或按用户偏好）、长度 ≤ 半页。
- [ ] 人称只用“本文/本章/本节”；无“我们/笔者/更令人惊讶的是”。
- [ ] 无“由于页面限制/篇幅所限”等期刊式语句；无重复冗余（“在本章中，本章……”）。
- [ ] 术语全文统一（同一概念只用一种中文译名；并列对象的语序固定）。
