# Launch Info

## Contract

- User objective, scope, existing authorization:
- Required stages/artifacts, acceptance metrics and guardrails:
- Absolute deadline/timezone, remaining budget:
- Budget reserved for validation and pullback:

## Immutable inputs

- Project/run ID/attempt ID:
- Host/port (no authentication material), workdir/run root:
- Code commit and dirty-file hashes, or file manifest:
- Config snapshot/hash, checkpoint revision/hash:
- Dataset/split/expected IDs and label mapping:
- Actual Python absolute path, environment and package versions:
- CUDA/GPU, verified model/cache paths:
- Actual entrypoint and non-secret arguments:

## Launch and observation

- Preflight and actual CLI smoke evidence:
- Throughput and peak memory (units), concurrent jobs:
- Session/job ID, wrapper/process PID and start identity:
- Log/identity/exit-code paths:
- First meaningful batch/epoch/result:
- Last verified observation time/state:
- Current stage and required next-stage gate:

## Notifications (off unless requested)

- Authorized channel/recipient/events:
- Declared overall progress source:
- Private credential injection method (never its value):
- State path and delivery/preview status:

## Results and recovery

- Expected complete artifacts and validation:
- Authorized pullback list/destination/size budget:
- Completed local copies and checksum/parse evidence:
- Process exit status; experiment acceptance status:
- Failed attempts and cause/evidence:
- Resume checkpoint and required verification:
- Remaining work and next executable action:
